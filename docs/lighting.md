# Lighting

## Flat look (Slack style, decided 7 Nov 2026)

In-content surfaces are flat: no gloss, no gradient, no shadow. A `--border` hairline separates them (list rows touch with no divider; chips, cards, buttons, bubbles, headers and the phone dock draw a hairline or nothing). Only floating layers (sheets, menus, dialogs, toasts, the unread pill: `lit-float`, `lit-overlay`) keep their soft shadow. Every `lit-*` class stays on its surface; only token values changed, all in one block at the end of the token section of `src/index.css` (`/* FLAT LOOK ... */`, selector `:root, .dark`, after `.dark`, before `@layer base`). Guard: `src/__tests__/flat-look.test.ts`.

Token block summary (light and dark alike):

- `0 0 #0000` (no shadow): `--lit-hl`, `--lit-raised`, `--lit-card`, `--lit-btn-primary`, `--lit-btn-success`, `--lit-btn-danger`, `--lit-btn-secondary`, `--lit-chip`, `--lit-well`, `--lit-well-soft`, `--lit-pill`, `--lit-tint`, `--lit-active`, `--lit-media`, `--lit-avatar`, `--lit-badge`, `--lit-bubble-own`, `--lit-bubble-other`, `--lit-strip`.
- `none` (no gradient): `--lit-surface`, `--lit-chip-bg`, `--lit-overlay-bg`, `--lit-bubble-other-bg`, `--lit-shine`, `--lit-muted-shine`.
- `var(--border)`: `--lit-edge-top`, `--lit-edge-side`, `--lit-edge-bottom` (edge classes draw one even hairline).
- Hairlines only: `--lit-header: 0 1px 0 var(--border)`, `--lit-side: 1px 0 0 var(--border)`, `--lit-dock: 0 -1px 0 var(--border)`.
- Unchanged: `--lit-float`, `--lit-overlay`, `--lit-knob`, `--sel-edge`, `--lit-dock-joined`, `--shadow-spotlight`, the outline family (`lit-selected`, `lit-focus`, `lit-focus-inset`, `lit-bad`, `lit-drop`, `lit-today`), `--hover-fill`, `--press-fill`.
- Dark `--border` lifted `#1c1d1e` to `#2a2c30` (`--border-rgb: 42 44 48`) so the hairline reads on near-black with no shadows.

A surface that relied on its shadow to be seen takes `border border-border`, never a shadow. Call sites never carry `box-shadow`, `shadow-*`, `drop-shadow`, `backdrop-blur` or `dark:` (only the ImageLightbox and FileViewer backdrops keep their blur). Guard: `src/__tests__/lighting-rules.test.ts`.

## Before 7 Nov 2026 (superseded)

Superseded 7 Nov 2026 by the flat look above; kept for the class map below. One light, straight above the screen, in light and dark mode. Raised things had a bright top edge, a darker bottom edge and a shadow falling down. Sunken things (inputs, tracks) had shade on the top inner edge. Dark mode: higher was a lighter surface, plus a dark outline ring. The "Looks like" column of the Heights table and the Tokens table describe these pre-flat raw values; the effective values are the FLAT LOOK block.

Every surface takes exactly one `lit-*` class from `src/index.css` (`@layer components`). The guide spotlight keeps `--shadow-spotlight` (a cut-out, not a light). At most one soft (blurred) shadow per token (`lighting-rules.test.ts`).

## How the classes combine with utilities

- Lit classes sit in the components layer, so utilities on the same element win; the outline family (below) sits in `@layer utilities` at the end of `src/index.css`, so it always wins. Gradients are `background-image`, so the element keeps its own `bg-*` colour underneath.
- Edge classes (`lit-raised`, `lit-card`, `lit-card-muted`, `lit-overlay`, `lit-chip`) set the border colour (top light, sides mid, bottom dark): drop the neutral `border-border` utility, keep the width. State outlines come only from the outline family below.
- `lit-header`, `lit-side`, `lit-dock` turn their border transparent and draw it as part of the shadow. A non-sticky header lifts to `position: relative; z-index: 1` so its shade paints over the next sibling; sticky headers keep their own position and z-index.
- Browser bar strips (no new height): the phone chat thread strip (`ThreadTopStrip`, MessageThread.tsx) and the homepage strip (`.home::before`, home.css) fill only the status bar inset, solid `bg-panel` / `--panel`, so iOS Safari samples a solid top edge. Each is part of the surface below it (the thread header, `lit-header`; the homepage `.top`), takes no `lit-*` of its own and adds no rim, blur or opacity. 0px tall without an inset.
- `lit-selected` replaces the element's own `lit-card` / `lit-chip` on the picked state (it carries the chip light); drop the selected-state fill and accent border utilities.
- Never transition `box-shadow`, `filter` or `backdrop-filter`.

## Fields, edges and states

- Fields: ui/Input, Textarea, Select, DatePicker, Checkbox and the code boxes draw `border-field` (`--field-line`: ink `#08090a` light, `rgba(255, 255, 255, 0.92)` dark, the same as `--sel-edge`) at rest, on `bg-panel-2` with `lit-well`; focus adds `lit-focus`; errors `lit-bad`.
- Search (ui/Input `tone="search"`): a tool, not a field to fill. At rest a filled well: `border-transparent bg-panel-2 lit-well`, no line, icon `fg-3` (exempt from the 3:1 edge rule: no edge is drawn). Focused it becomes the centre: `border-field` + `lit-focus`, the surface lifts to `bg-panel lit-card`, caret and icon full ink (the focused line is 3:1, guard: contrast-rules.test.ts). Every `type="search"` input takes the tone (guard: outline-rules.test.ts). Chips (7 Nov 2026) are an outline pill (`rounded-full border`, 32 visible / 44 tap): at rest a hairline and `fg-2` ink (`border-border text-fg-2`); the pick is the ink line and `fg` ink (`border-fg text-fg`), no fill; counts `fg-3`.
- Drawers and sheets over a page are grey (`bg-bg` under `lit-overlay`) with lit cards (`rounded-xl border bg-panel lit-card`), rows inside separated by `border-t border-border`; never a white sheet of flat rows. Chat open-items drawer (chat/StatusDrawer): each section and each plan section is one card; section counts are ui/CountBadge `tone="section"` (`lit-pill bg-panel-2 border-border-strong rounded-full`, mono digits); post covers (POST_COVER_BOX) `border border-border lit-media`.
- Dock joined (flat: `--lit-dock` is a top hairline only): while the composer tray is open the composer bar takes `lit-dock-joined` (no top highlight, no top line, no upward shade: `--lit-dock-joined: none` in both themes, top border transparent) and the tray above it keeps `lit-dock`, so tray and bar read as one dock with no seam in dark. Closed: the bar is `lit-dock`.
- Edges: `border-strong` (`#868b94` light, `#6b7079` dark, 3:1 on bg, panel and panel-2) is the edge of a control at rest: chips, switch tracks, unchecked SelectCheck, carousel and guide dots, read bars, track rings. `border-border` is a divider inside a surface only.
- Hover: `--hover-fill` (`rgba(8, 9, 10, 0.08)` / `rgba(255, 255, 255, 0.1)`) stacked over the surface's own gradient (`--lit-bg`), so the light stays. `lit-chip`, `lit-selected` and interactive `lit-card` / `lit-card-muted` get it for free; anything else that hovers (PressableRow, ghost buttons, IconButton, div cards) carries `lit-hover`; the Button level (secondary) hovers by its own fill step (bg-fg/10 to bg-fg/15). Never `hover:bg-panel-2/3`, never `background-image: none`, never opacity.
- Press: `--press-fill` (`.14` / `.16`) on `:active`, same stacking.
- A pick in a single-choice row (7 Nov 2026: chip rows, preview sizes, Settings tabs, Book a call and platform and onboarding side radios, Cockpit tiles, file viewer sheet tabs, who-reacted tabs, emoji group tabs): the ink line, `border border-fg text-fg`, no fill, no `lit-pill`, no `lit-well-soft`; idle options rest on a hairline, `border border-border text-fg-2`. It switches instantly (no slide). Own looks, not this rule: the phone nav (active tab `bg-panel-3` fill + label; Chat circle active = ink fill), Plan day tiles, the Sidebar and laptop Activity button (solid ink fill). Other selected, open, active, current states: `lit-selected`.
- Disabled: `fg-3` ink, no hover, no press light, no shadow on a primary (`bg-fg-3 text-accent-fg`). Never opacity.
- Switch: off track `bg-panel-2` + `border-strong` + `lit-well`; on track `bg-accent`; knob `bg-knob` (`#fff` light, `#1d1e21` dark: lighter than its track) with a `border-strong` ring and `lit-knob`.
- Own chat bubble: every line and fill inside uses `on-bubble/*` (`#fff` light, `#08090a` dark); the outline family inside `[data-own]` draws in `--on-bubble`, cards in the bubble keep their own ink.
- Dark document pages and thumbnails: `lit-page` (brightness .86 in dark only).
- Undo strip: `lit-strip` (a faint top line) instead of `lit-float`, both themes.

## Light while moving (docs/motion.md)

Light stays put while things move: one point straight above. A moving surface keeps its `lit-*` class through every move (push, grow, rise, glide, strips). No new heights for motion:

- Loading boxes (`Bone`, `BoxSkeleton`, `mv-bone`) take a required `lit` prop, the class of what replaces them (`lit-card`, `lit-well`, `lit-avatar`, `lit-media`, ...; `flat` for text lines and inner fills); the sweep inside is **Flat**: a `panel-3` fill with a top-lit sweep band (`--panel` tint in light, a faint ink lift in dark: higher is lighter). No shadow.
- A dragged board card lifts **one** height: Card to Float (`lit-card` to `lit-float`) and scales to 1.02 (`mv-lift`).
- A pressed control sinks (scale .97, `mv-press`); its `lit-*` class does not change.
- A pushed screen's incoming edge is a 1px ring (no shadow).
- The sheet backdrop dim (`bg-scrim`) tracks the sheet's position; it is not a surface.

The person photo viewer (ui/PhotoViewer) is a full-screen media surface like the image lightbox: `bg-overlay`, no lit class of its own; the photo keeps `lit-avatar`.

The person card's inline message sits on its sheet or popover (Overlay); its input box is Sunken (`lit-well`).

## Outlines

One outline family, from `--sel-edge` (`#08090a` light, `rgba(255, 255, 255, 0.92)` dark): a crisp ink line in light, a crisp white line in dark. No accent tint, no glow. Guard: `src/__tests__/outline-rules.test.ts` (no `border-accent`, `border-accent-line`, `ring-accent`, `lit-chip-selected` on a call site).

| Class             | Draws                                                       | Where                                                                                                                                                                                                                                                       |
| ----------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lit-selected`    | `--sel-edge` border, chip gradient and `--lit-chip` light   | open, active or current state (never a single-choice pick, which is the ink fill): Select and Sort menu picked option, open chat row, Sidebar / tab active, palette highlighted row, message select mode, search and comment arrival flash, today Plan card |
| `lit-focus`       | `outline: 1.5px solid --sel-edge`, offset 2px               | `focus-visible:lit-focus` on Button, IconButton, Chip and other focusable call sites                                                                                                                                                                        |
| `lit-focus-inset` | the same line, offset -2px                                  | rows inside `overflow-hidden` cards, so the line is not clipped                                                                                                                                                                                             |
| `lit-bad`         | `--bad` border colour, keeps its own lit class              | error inputs, failed (Not sent) bubbles                                                                                                                                                                                                                     |
| `lit-drop`        | 1px dashed `--sel-edge` border plus inset ring on `--panel` | DropZone while dragging, plan drop slot, board drop                                                                                                                                                                                                         |
| `lit-today`       | inset 1px `--sel-edge` ring, no fill                        | today's column or cell in the Plan calendar                                                                                                                                                                                                                 |

Focus is an outline, never a box-shadow, so it never wipes a surface's light or fights a moving shadow. Exceptions: overlay controls on media (lightbox, file viewer, photo viewer) keep their own white ring; the induction spotlight keeps `--shadow-spotlight`.

## Coverage

Anything with a fill (`bg-panel`, `bg-panel-2`, `bg-panel-3`, `bg-bg`, `bg-*-soft`) plus a radius plus a border or padding takes a `lit-*` class (guard: `src/__tests__/lit-coverage.test.ts`, allow list with reasons). Pages are grey (`bg-bg`) with lit cards. Loading shells take the same class as the card that replaces them; only the Bones inside sweep.

Emails: one look from one shell, `packages/inbox/src/email-shell.ts` (edge functions carry verbatim copies, guard `email-shell.sync.test.ts`; the Supabase Auth templates are generated from `auth-templates.ts`). Light and dark: both color-scheme metas and a `prefers-color-scheme: dark` block with an Outlook `[data-ogsc]` mirror; every colour is a light/dark token pair. Lit edges drawn with borders, no shadows: grey page (`#f4f5f6` / `#08090a`), card radius 12 with a quiet edge `#d7dade` / `#2a2b2f`, lighter top `#eceef1` / `#36383d` and a 2px bottom line `#c9ced5` / `#050506`. The code box and buttons use the 3:1 line `#868b94` / `#6b7079`; code box fill `#f2f3f5` / `#16171a`, code in mono 28px with .2em tracking. Buttons: ink fill and white text in light, white fill and ink text in dark, 2px bottom in the 3:1 line, never a pure black rim. Secondary links are underlined. Header: the Sorted wordmark image (`public/email/wordmark-light.png` / `wordmark-dark.png`, 2x, alt "Sorted"), never a blank square. Catch-up stat numbers are mono with tabular figures. Black and white only; amber, green and red only for status. Guards: `src/__tests__/email-look.test.ts`, per-email render tests, `e2e/visual/emails.spec.ts`.
